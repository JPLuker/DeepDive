setlist.fm CORS check

This decides whether DeepDive can reach setlist.fm at all. A browser-only app can't call an API that doesn't send CORS headers, and every concert feature after 3.0 depends on the answer.

Open this from jpluker.github.io, not from a file on disk — a local file has the origin null, which servers treat differently, so a local result would tell you nothing.
